## ✨ المميزات الرئيسية

1. **التحكم الديناميكي في عدد المجموعات (من 2 إلى 12 مجموعة):**
   - إضافة وحذف وتعديل عدد الفرق بضغطة زر واحدة.
   - بحد أقصى **4 مجموعات في الصف الواحد أفقياً**، وتنزل المجموعات الإضافية لأسفل تلقائياً للحفاظ على تنسيق شاشة مريح.

2. **المشاركة الحية والتعديل المتزامن (Real-Time Cloud Collaboration):**
   - قاعدة بيانات سحابية متصلة على مدار الساعة (Supabase Cloud DB) لحفظ أي تعديل يقوم به أي شخص ومزامنته مع باقي الأجهزة تلقائياً.
   - زر **"مشاركة الرابط 🔗"**: ينشئ رابطاً مباشراً محمولاً يحمل نفس التوزيعة ليتمكن أي شخص من فتحه على هاتفه أو حاسوبه بدون الحاجة لتسجيل دخول.

3. **قرعة عادلة مع تثبيت القادة الأساسيين (👑):**
   - تثبيت القادة في أماكنهم عند إجراء القرعة العشوائية، وإعادة توزيع باقي الأعضاء بالتساوي التام.

4. **السحب والإفلات والتعديل المباشر (Drag & Drop):**
   - نقل أي عضو بين الفرق بالسحب والإفلات أو بزر النقل المخصص.
   - تعديل أسماء الأعضاء وأسماء الفرق وشعاراتها (الإيموجي) في أي وقت.

5. **تكامل متقدم مع WhatsApp و Excel و Google Sheets:**
   - نسخ كشف الفرق بالكامل بضغطة واحدة منسقاً وجاهزاً للإرسال على الواتساب.
   - تصدير كشف كامل بصيغة Excel / CSV.
   - مزامنة كشف الأسماء لحظياً في الخلفية مع Google Sheets.

6. **وضع العرض للبروجكتور والطباعة الأنيقة:**
   - وضع عرض شاشة كاملة (Full Screen) مخصص لأجهزة العرض والشاشات الكبيرة بدون أزرار أو حشو.
   - طباعة نظيفة A4 خالية من الصور غير المرغوبة.

## 💻 التشغيل المحلي (Local Development)

إذا أردت تشغيل السيرفر المحلي مع المزامنة التلقائية لملف Google Sheets:

```bash
# تشغيل السيرفر المحلي
node server.js
```

افتح المتصفح على:
`http://localhost:8080/`
